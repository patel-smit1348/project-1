# WeIntern Data Science Internship — Week 1

## Objective
Complete the Week 1 e-commerce data cleaning, sales analysis, visualization, and reporting requirements.

## Dataset note
The WeIntern Week 1 handbook did not include a dataset. Therefore, this repository uses a **synthetic e-commerce dataset** created for this assignment, with fields aligned to the handbook. This is stated explicitly so the submission does not misrepresent the data source.

## Tools
Python, Pandas, NumPy, Matplotlib, Jupyter Notebook

## Key KPIs
- Total Revenue: 8,683,007.44
- Total Orders: 367
- Average Order Value: 23,659.42
- Total Units Sold: 1075
- Top Category: Electronics
- Top Revenue Product: Laptop

## How to run
```bash
pip install -r requirements.txt
jupyter notebook
```
Open `notebooks/week1_analysis.ipynb` and run cells from top to bottom.

## Important
The raw dataset is kept separate from the cleaned dataset. Cleaning decisions are documented in the notebook and final report.
